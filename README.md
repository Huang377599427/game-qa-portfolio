# 游戏测试个人作品集

## 测试对象
XX游戏 v1.2.3

## 测试范围
登录模块（手机号验证码、账号密码、第三方登录、游客登录）

## 测试环境
- 设备：小米14、iPhone 15
- 系统：Android 14、iOS 17
- 网络：Wi-Fi、4G、弱网、断网

## 测试方法
等价类划分、边界值分析、场景法、状态迁移、错误推测

## 产出
- 30条测试用例，覆盖功能、异常、边界、网络、中断、安全、兼容、性能
- 3份规范Bug报告，包含环境、步骤、预期、实际、复现率、严重程度、优先级、附件
- 1份测试小结

## 个人收获
熟悉游戏登录模块测试点，掌握用例设计和Bug报告规范，能独立完成模块测试。
